🛠️ DIY: Build your Vanilla RNN to forecast Time Series data

Theory is essential, but code is where the magic happens. To build our forecasting model, we’ll use Keras for the neural network architecture and Scikit-Learn to handle the data preprocessing. This combination allows us to focus on the RNN logic without getting bogged down in manual matrix multiplication.

Let’s start by importing our essential Data Science libraries:

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.preprocessing import MinMaxScaler
from sklearn.metrics import mean_squared_error

1. Generating and Preparing the Data

Instead of downloading an external dataset, we will generate our own noisy wave. This guarantees you can reproduce these exact results.

# Generate 1000 data points of a sine wave with some random noise
time_steps = np.arange(0, 100, 0.1)
data = np.sin(time_steps) + np.random.normal(scale=0.1, size=len(time_steps))

# Put it into a pandas DataFrame
df = pd.DataFrame(data, columns=['Value'])

# Plot the first 200 points to see our pattern
plt.figure(figsize=(10, 4))
plt.plot(df['Value'][:200])
plt.title("Noisy Cyclical Data")
plt.show()

This plot helps verify that our data generation worked. You'll see a clear, repeating wave pattern, but with jagged, irregular edges caused by the np.random.normal noise we injected.

Scaling the Data

Neural Networks are highly sensitive to the scale of the input data. Since we will be using the tanh activation function (which outputs values between -1 and 1), it is best practice to scale our data. Here, we will scale everything to be strictly between 0 and 1.

# Initialize the scaler
scaler = MinMaxScaler(feature_range=(0, 1))
scaled_data = scaler.fit_transform(df)

2. Reframing as a Supervised Learning Problem

RNNs cannot just ingest a long list of numbers. We need to create a “sliding window” of data. We will use a sequence of previous steps (e.g., the last 20 points) to predict the very next step.

# Initialize empty lists
X = []
y = []

# Set the number of historical steps the model will look at
timesteps = 20

# Iterate to populate the lists
for i in range(len(scaled_data) - timesteps):
    X.append(scaled_data[i : i + timesteps, 0])
    y.append(scaled_data[i + timesteps, 0])

# Convert lists to numpy arrays
X = np.array(X)
y = np.array(y)

Neural Networks employ a unique input structure. Specifically, for RNNs, the dimensions of the input tensor must be exactly three-dimensional: [number of samples, number of timesteps, number of features].

Currently, our X array is two-dimensional. We only have one feature (the value itself), so we need to reshape our array to explicitly include that feature dimension.

# Reshape X to [samples, timesteps, features]
X = X.reshape(X.shape[0], X.shape[1], 1)

print(f"X shape: {X.shape}")
print(f"y shape: {y.shape}")

Output: 

X shape: (980, 20, 1), y shape: (980,)

We started with 1000 data points. Because our sliding window requires 20 historical points to make its first prediction, we "lose" the first 20 steps, leaving us with 980 usable samples. The 20 represents the historical timesteps our model looks at for each sample. The 1 is our single feature (the value of the sine wave). The y array naturally has 980 corresponding target values.

3. Train/Test Split

Let’s select 80% of the data for training and the remaining 20% to test our model’s performance. Crucial note: Because this is time-series data, we must split it sequentially. We cannot randomly shuffle the data, or we will leak the future into the past!

split_idx = int(X.shape[0] * 0.8)

X_train, X_test = X[:split_idx], X[split_idx:]
y_train, y_test = y[:split_idx], y[split_idx:]

4. Building the Vanilla RNN Model

First, import the required Keras modules:

from keras.models import Sequential
from keras.layers import SimpleRNN, Dense

Let’s build the model. We will use a single SimpleRNN layer followed by a Dense layer to output our single prediction.

  • Units: We’ll use 16 neurons. Since our dataset has a clear pattern, we don’t need a massive network.

  • Activation: We use tanh, which is standard for RNNs as it helps mitigate vanishing gradients better than sigmoid.

  • Dropout: We are intentionally skipping the Dropout layer here. While dropout is great for complex, noisy data (like stocks) to prevent overfitting, applying it to a simple, deterministic pattern often just introduces artificial noise and prevents the model from learning the curve smoothly.

# Initialize the Sequential model
model = Sequential()

# Add an RNN layer with 16 units
model.add(SimpleRNN(16, 
                    activation='tanh', 
                    input_shape=(X_train.shape[1], 1)))

# Add a Dense layer with 1 unit to output the final prediction
model.add(Dense(1))

# Compile the model using Mean Squared Error and the Adam optimizer
model.compile(loss='mean_squared_error', optimizer='adam')

model.summary()

The (None, 16) output shape means the layer outputs 16 values (our 16 units), while None is just a placeholder representing a variable batch size. The 288 parameters in the RNN layer come from three sets of weights: the input-to-hidden weights (1 feature × 16 units = 16), the hidden-to-hidden recurrent weights (16 units × 16 units = 256), and the biases (16). Added together, 16 + 256 + 16 = 288. Finally, the Dense layer has 17 parameters (16 incoming weights from the RNN + 1 bias).

5. Training the Model

We will train the model for 30 epochs. We will also use a validation_split to monitor how well the model generalizes to unseen data during training.

# Fit the model
history = model.fit(X_train, y_train, 
                    epochs=30, 
                    batch_size=16, 
                    validation_split=0.1, 
                    shuffle=False, # Remember, no shuffling in time series!
                    verbose=1)

Let’s visualize the training process to ensure our loss decreased smoothly:

plt.figure(figsize=(8, 4))
plt.plot(history.history['loss'], label='Training Loss')
plt.plot(history.history['val_loss'], label='Validation Loss')
plt.title('Model Loss Over Time')
plt.legend()
plt.show()

A line graph with two downward-trending curves. The 'Training Loss' (how well the model fits the training data) and 'Validation Loss' (how well it performs on the 10% hold-out set) should both drop rapidly in the first few epochs and then smoothly level out. Because they track closely together without the validation loss spiking back up, it confirms our model is learning successfully without overfitting.

6. Evaluating the Results

Now for the moment of truth. Let’s make predictions on our test set and see if the model successfully learned the cyclical pattern.

# Generate predictions
y_pred = model.predict(X_test)

# Inverse transform to get the values back to their original scale
y_test_scaled_back = scaler.inverse_transform(y_test.reshape(-1, 1))
y_pred_scaled_back = scaler.inverse_transform(y_pred)

# Calculate RMSE
rmse = np.sqrt(mean_squared_error(y_test_scaled_back, y_pred_scaled_back))
print(f"Test RMSE: {rmse:.4f}")

Output:

Test RMSE: 0.1221

RMSE (Root Mean Squared Error) measures the average magnitude of our model's errors. An RMSE of 0.1221 on a dataset that naturally fluctuates between roughly -1.2 and 1.2 is very low. It tells us that our model's predictions are, on average, only off by about 0.12 units from the true values.

You should see a very low RMSE score. To truly appreciate the results, let’s plot the actual values versus the model’s predictions.

plt.figure(figsize=(12, 5))
plt.plot(y_test_scaled_back, label='Actual Data', color='blue')
plt.plot(y_pred_scaled_back, label='RNN Predictions', color='red', linestyle='--')
plt.title('Vanilla RNN: Actual vs Predicted')
plt.legend()
plt.show()

Your plot shows the red dashed line (predictions) hugging the blue line (actual data) almost perfectly. The Vanilla RNN has successfully learned the underlying sequential logic of the dataset! Notice how the model doesn't just blindly copy the previous step; it actively anticipates the curve's peaks and valleys, demonstrating that it has captured the true temporal pattern.
